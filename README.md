# Daramola Adeoluwa Portfolio

## Project Description
A responsive personal portfolio website built with React JS for Daramola Adeoluwa. The project presents the developer's profile, services, mission, and contact form while demonstrating core React concepts such as components, props, state, event handling, form validation, and routing.

## Technologies Used
- React JS
- React Router DOM
- JavaScript
- HTML
- CSS

## Installation
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:
   npm install
4. Start the app with:
   npm run dev

## Project Features
- Home page with welcome section and key statistics
- About page with mission and values
- Services page using reusable cards and .map()
- Contact page with controlled form inputs and validation
- Responsive layout for mobile, tablet, and desktop devices

## Deployment
This project can be published on Netlify, Vercel, or Render using the build command:
npm run build
